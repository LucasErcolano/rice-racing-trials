## API de evidencia (`client/detectors.lua`)

- `off_course{source='ac_physics_numberOfTyresOut', min_out=2}` → `observe({numberOfTyresOut=0..4})`: cuenta **episodios de ruedas fuera** sólo en flanco de entrada, después de vuelta a menos del umbral. `unknown` para muestra faltante/errónea; ni aproxima cono ni entrega penalización oficial. Confianza `physics_proxy_uncertified`.
- `slalom{version='slalom-gates-v1',status='surveyed',survey_id=...,asset_sha256=...,gates={...}}`: cada gate requiere `id`, `a,b,pylon` en AC x,z metros, `direction` ±1, `side` left/right alternado y `clearance_m` positivo. `side` significa proyección negativa/positiva de `a→b` respecto al pilón; **no** izquierda/derecha del conductor. Segmentos deben ser dirigidos y medidos. Se rechazan falta de plano, punto inválido, secuencia incorrecta, paso por lado equivocado o muestreo que salta múltiples puertas. Sólo `sequence_observed`, nunca validación de recorrido completo ni resultado oficial. Confianza `surveyed_geometry_offline` incluso cuando el operador declara `surveyed`: la cadena de texto no prueba el levantamiento.
- `cones()` → `observe(evidence)`: proximidad o contacto genérico `collision` = `unknown`/`review`; sólo `operator_adjudication` con `cone_id`, `contact=true`, `decision='hit'`, `reviewer`, `evidence_id` contabiliza **decisiones humanas distintas por cono**, deduplicadas. Confianza `operator_review_only`, `official=false`; no detector físico ni feed automático implementado. El operador debe conservar vídeo/telemetría referidos por `evidence_id` fuera del motor.
- Ninguno está conectado a `core.lua`, `RiceTrials.lua` ni al servidor. La sesión, el track hash, el rig y las reglas deben verificarse externamente; jamás confiar en una etiqueta `surveyed` suministrada por cliente para publicar clasificación.
