# Cronometraje nativo: análisis reproducible, sin parche activo

`python3 -m timing.audit assets/source/FSAEJ_Endurance.zip FSAEJ_Endurance --output timing/endurance-native-evidence.json` lee `Dummy.kn5` sin extraer ni modificar la pista. El hash obtenido del dummy coincide con `track/calibration/timing-landmarks.json`. Los marcadores del modelo medidos en coordenadas AC (m) son `AC_START_0=(-127.292,1,30.452)`, `AC_HOTLAP_START_0=(-59.698,1,31.651)`, `AC_PIT_0=(-153.783,1,32.611)`; `AC_TIME_0_L=(-108.581,1,42.438)` y `AC_TIME_0_R=(-115.773,1,42.438)`. La distancia plana entre el spawn `AC_START_0` y el punto medio de la línea es **19.291 m**. Esto explica que el spawn no esté sobre la línea, pero no permite deducir el tiempo recorrido ni la regla exacta del Best Lap.

En el repositorio del creador del mod `JSAE-ARCHIVES/FSAEJ-simulator`, `InvalidateLap/InvalidateLap.py` usa `ac.ext_markLapAsSpoiled()` para invalidar una vuelta por ruedas fuera de pista. Esa app **no corrige** el inicio nativo de la primera vuelta, no es una API Lua confirmada y el propio README advierte que su conteo de toques de conos puede perder golpes consecutivos o rápidos. El README recomienda Practice o Hotlap, no Time Attack, y distingue las posiciones de salida de pits/start en Practice.

Alternativas ordenadas para el rig: (1) probar Practice desde starting line y Hotlap con la pista intacta, observando `LapCount`, `LapTime` y `Best Lap` al salir y cruzar meta; (2) buscar en CSP una API soportada para invalidar el outlap nativo, **sin asumir** que la función Python anterior tenga equivalente Lua; (3) estudiar un cambio mínimo y reversible de spawn o timing dummies, con backup y copia del KN5 original, solo si el comportamiento medido exige ello. **No se entrega un KN5 modificado ni parche candidato** porque sin ejecución en Assetto no se puede escoger una transformación correcta ni verificar si el motor usa el dummy cargado como esperamos.

El scoring propio debe descartar el outlap por estado y secuencia de checkpoints; no confundirlo con la pantalla Best Lap nativa. El archivo JSON de evidencia no activa scoring ni calibración.
