## Reutilización y límites

`tools/trackgen.py`, `tools/kn5.py`, `tools/course_maps.py`, `analysis/track_geometry.py`, `tools/validate_fsae_2027_tracks.py` y las definiciones JSON permiten estudiar/generar/comprobar los **fallback Rice**; `docs/*COURSE_MAP*` y `commissioning/public_tracks/audit/maps/` sirven para revisión visual. `config/track_lock.json` y `config/FROZEN_TRIAL_CONFIGURATION.json` son relevantes para preflight; cualquier sustitución requiere nueva configuración y validación, no renombrar una carpeta. Las carpetas oficiales, sus archivos de mod, el automóvil MFT02 y Assetto no están en el ZIP. Las afirmaciones de procedencia JSAE, comisionamiento Windows, fidelidad del trazado y cumplimiento reglamentario se tomaron de documentos internos; no se contrastaron con levantamiento CAD/GPS, archivos originales externos ni ejecución del simulador. Tampoco se validó FFB, controles humanos, coeficientes de adherencia o dinámica del vehículo. `official_enabled=false`: este inventario no constituye habilitación para pruebas oficiales.
